迅达采购订单批量识别

勾选字段并保存方案 → 点击列头改格式、拖动调整顺序 → 导出表格

同一张 PO 里多条行项目（00010、00020…）会各成一行；描述换行会拼进同一行。 行下新出现的「字段: 值」会自动发现为关键字。空附加字段仍可勾选导出。 供应商、交货地址、付款条件勾选才导出。 导入后可在「识别内容」里按订单核对数量、单位和原件。 若出现跨页续行、无物料号文本行、服务类行，识别区会提示人工核对。

1. 导入识别

拖入多个迅达采购订单 PDF，或点击选择 浏览器本地识别，文件不会上传到服务器

2. 识别内容 · 对照原件核对

抬头摘要固定在上方。订单卡片在框内滚动，不会一次铺开。缺项会标红；点识别结果行可跳到对应订单。

3. 导出字段与关键字

核心订单行默认导出。选配抬头（含公司代码、工厂）默认关闭。抬头关键字如「公司代码」会对应识别值。文档里新出现的「颜色」等会自动列入关键字。

导出方案

保存当前勾选的字段、自定义关键字、列顺序、列名与格式，以及下方 BOM 模板、变量映射和料号对照，下次直接应用。

4. 识别结果 · 勾选要输出的行

筛选只改变可见行，导出仍按勾选。可用「全选可见」只勾当前结果。

5. 输出表格 · 点击列设置格式

只输出上方勾选的行。点击表头改列名和格式，拖动左侧手柄或用左移 / 右移调整列顺序。格式用 {字段名}，以 = 开头计算，例如 ={数量}*2、=IF({数量}>3,"大","小")、=TEXT({凭证日期},"yyyy-mm-dd")、=TEXT({凭证日期},"yyyy/m/d")、{物料描述}&" / "&{图号/版本}。

列格式

6. BOM 子件用量 · 公式模板与料号对照

导入带备注 / 公式列的表格模板，自动识别公式中的变量。每个变量可映射到识别结果的某一列、一条公式，或固定值。 对上方勾选的每一行订单算出各子件数量。可选再导入一张料号对照表：匹配到该行物料号的数据会接在该订单 BOM 下方。映射随导出方案一起保存。

BOM 模板

拖入 Excel / CSV，或点击选择 表头含「备注」「公式」或单元格以 = 开头

料号对照（可选）

拖入对照表 Excel / CSV，或点击选择 按订单物料号匹配，命中行追加到该行 BOM 下方

变量映射

公式中识别到的变量。来源可以是识别列、导出列、公式或固定值。
