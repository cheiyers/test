同一张 PO 里多条行项目（00010、00020…）会各成一行；描述换行会拼进同一行。 行下新出现的「字段: 值」会自动发现为关键字。空附加字段仍可勾选导出。 供应商、交货地址、付款条件勾选才导出。 导入后可在「识别内容」里按订单核对数量、单位和原件。 若出现跨页续行、无物料号文本行、服务类行，识别区会提示人工核对。

导出方案

保存当前勾选的字段、自定义关键字、列顺序、列名与格式，以及 BOM 列表、变量映射、料号对照和最终导出模板列对应，下次直接应用（替换列表，不会追加重复）。

筛选只改变可见行，导出仍按勾选。可用「全选可见」只勾当前结果。

这里是勾选订单行的预览，不含 BOM 展开。最终导出请到第 7 步按模板输出 BOM 计算结果。 点击表头改列名和格式，拖动左侧手柄或用左移 / 右移调整列顺序。格式用 {字段名}，以 = 开头计算，例如 ={数量}*2、=IF({数量}>3,"大","小")、=IFS(AND({数量}>=4,TRUE),ROUNDUP({数量}*1.1,0),TRUE,{数量})、=TEXT({凭证日期},"yyyy-mm-dd")、=TEXT({凭证日期},"yyyy/m/d")、{物料描述}&" / "&{图号/版本}。 与 Excel 相近的常用函数（含中文名如 如果、求和）均可用于列格式和 BOM 备注。

列格式

可上传多份 BOM 模板（带备注 / 公式列），列表里可继续添加、替换或删除。公式中的变量可映射到识别列、公式或固定值。 备注公式支持 Excel 常用函数（IF / IFS / AND / ROUNDUP / VALUE / CONVERT 等，也可用 如果、求和）。 对上方勾选的每一行订单，按勾选的 BOM 算出各子件数量。计算结果在框内滚动查看。可选再导入一张料号对照表：匹配到该行物料号的数据会接在该订单 BOM 下方。映射随导出方案一起保存。

BOM 模板

拖入 Excel / CSV，或点击选择 可多次添加。表头含「备注」「公式」或单元格以 = 开头

料号对照（可选）

拖入对照表 Excel / CSV，或点击选择 按订单物料号匹配，命中行追加到该行 BOM 下方

变量映射

公式中识别到的变量。来源可以是识别列、导出列、公式或固定值。

导出内容是上方 BOM 计算后的每一行（一行订单展开为多个子件，对照行接在后面）。预览在框内滚动，不一次铺开。 可上传带表头的 Excel/CSV 作为导出模板；每列对应 BOM 计算结果、识别订单列、公式或固定值。映射到识别订单列时，取该子件所属的那一行订单，不会把所有行写成同一份数据。 也可指定某列为空或为 0 时不导出该行，或选择仍然导出。

导出模板（表头）

拖入表头 Excel / CSV，或点击选择 只读第一行作为导出列名

列对应

模板每一列可对应 BOM 计算列、识别订单列、公式或固定值。

关闭则空值和 0 也导出。
