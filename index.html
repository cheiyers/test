这三份文件都是通力电梯有限公司采购订单，版式固定，真正要识别的「订单」是表格里的 Pos 行，不是整份 PDF 算一张单。

1. 抬头：PO 号、供应商、买方、送货地址、订单日期、账期、币种、总金额。
2. 订单行（主识别对象）：Pos / 物料号 / 到货日 / 数量 / 单价 / 金额 / 中英文描述 / Sales order ref. / Project ref. / 发货说明。
3. 行内规格：例如轿厢尺寸、吊顶材料、额定载重、Wire Length，左右分栏。
4. BOM 子件：.1 0010 KM…… 下层零件，以及子件下方的 Remarks line（A/B/C/D 等行信息）。
5. 页脚条款与签核栏每页重复，不作为订单行。

样张差异：4801006558 / 4801007230 是轿厢 LED STRIP 小单（各 4 行，合计 RMB 401.08）；4801169630 是主开关 + 井道照明电缆大单（254 行 / 117 页，合计 RMB 51,928.13）。下面表格就是按这个理解抽出来的结果，请先核对是否就是你要的内容。
