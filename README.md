# 迅达采购订单批量识别

浏览器端 HTML 工具：批量识别 SAP 迅达采购订单 PDF 的每一条行项目，勾选要导出的字段与行，改表头、写公式后导出 Excel / CSV。

## 导出规则

- **订单行字段**（采购订单号、凭证日期、行项目、物料号、单位、未税单价等）默认导出
- **选配抬头**：供应商、交货地址、付款条件、公司代码、工厂默认关闭；勾选才进入输出表，不勾选不导出。添加关键字「公司代码」等抬头字段会映射到已识别的值
- **导出方案**：把当前勾选的字段、关键字、列顺序、列名和格式存成方案，下次直接应用
- **多行项目**：同一张 PO 的 `00010`、`00020`… 各成一行；描述换行会拼进同一行
- **新字段**：行下新出现的「字段: 值」（如颜色、表面处理）会自动发现为关键字，勾选即可导出
- **可配置关键字**：图号/版本、安装国家、成组技术码、运输类型、D/E、产品家族、SCM大小/量纲。即使样张为空也保留，可勾选导出，也可自行添加关键字
- **行选择**：只输出勾选的识别结果行。可用筛选框按字段或全部列缩小可见行，再用「全选可见 / 可见全不选」，不必只靠全选/全不选
- **BOM 模板**：可上传多份带「备注 / 公式」列的 Excel 或 CSV，列表中可继续添加、替换或删除；自动识别公式变量（如 `数量`、`{轿厢宽度}`）。计算结果在框内滚动查看
- **变量映射**：每个变量可指定识别列、导出列、公式或固定值；对勾选的每一行订单、按勾选的 BOM 算出各子件数量
- **料号对照**：可选第二张表，按订单物料号匹配，命中行追加到该订单 BOM 下方
- **最终导出**：按 BOM 计算后的行导出，预览在框内滚动。可上传表头模板，把每列对应到 BOM 列或识别订单列（取该子件所属订单行，不会把所有行写成同一份数据），也可写公式/固定值。可选择某列为空或为 0 时不导出该行，关闭则仍然导出
- **方案**：导出方案同时保存 BOM 列表、变量映射、对照表和最终导出列对应；应用方案会替换列表，不会追加出重复行
- **表头 / 格式**：点击输出表的列头，直接改列名和输出格式
- **列顺序**：拖动表头左侧手柄，或在列格式栏里左移 / 右移；顺序会随方案一起保存
- **公式**：`{字段名}` 取识别值；以 `=` 开头计算。支持 `+ - * / ^ %`、`&` 拼接，以及与 Excel 相近的常用函数（逻辑、数学、统计、文本、日期、查找、信息、财务、进制与单位换算等），也可用中文函数名（`如果`、`求和`、`四舍五入`）。常用：`={数量}*2`、`=IF({数量}>3,"大","小")`、`=IFS(AND({数量}>=4,TRUE),ROUNDUP({数量}*1.1,0),TRUE,{数量})`、`=TEXT({凭证日期},"yyyy-mm-dd")`、`{物料描述}&" / "&{图号/版本}`
- **模块折叠**：第 1–7 步每个模块标题可折叠/展开，也可用「全部折叠 / 全部展开」。折叠状态会记住。点识别结果跳到订单时会自动展开「识别内容」。
- **识别内容核对**：导入后按订单展示抬头、行项目、数量、单位和原件预览。卡片在固定高度框内滚动，不一次铺开。缺数量/单位会标红；点击识别结果行可跳到对应订单。
- **需核对提示**：出现跨页续行、无物料号的文本行、服务类行时，导入区会给出黄色提示，对应结果行标「需核对」。常规物料行不提示。尚未自动拼接跨页或按服务行重算。

## 使用

```bash
python3 -m http.server 8080
```

打开 http://localhost:8080

- 页面先展示三份样张的预识别结果。点模块标题可折叠，顶部有全部折叠 / 全部展开
- 「加载双行+新字段样张」可核对一张 PO 两行（00010 / 00020）以及新关键字「颜色」「表面处理」
- 「加载需核对样张」可查看跨页续行、无物料号文本行、服务类行的提示效果
- 导入 PDF 后，「识别内容」卡片会列出每张订单的行项目（含数量、单位）和原件，便于纠错
- 也可拖入 / 选择多个 PDF，在浏览器本地识别
- 导出按钮生成当前输出表（含改过的表头与公式结果）
- 第 4 步可用筛选定位要导出的行，再「全选可见」
- 「加载示例模板 / 对照表」可试用 BOM：螺丝=`数量*4`，灯芯按轿厢宽度分档；对照表按物料号追加备用料。可继续上传加入列表，点替换修改某一份
- BOM 与最终导出预览都在固定高度框内滚动，不一次铺开
- BOM 结果可在第 7 步按表头模板导出；「加载示例表头」把物料编码/数量等对应到子件料号/计算数量，物料描述对应识别订单列（按该子件所属订单行取值）
- 勾选「为空或为 0 时不导出该行」可去掉用量为 0 或空的子件；不勾则全部导出
- 保存方案后可一并恢复映射与跳过规则

列公式把识别值转成需要的格式。日期改成 `yyyy-mm-dd` 用：

```
=TEXT({凭证日期},"yyyy-mm-dd")
=TEXT({交货日期},"yyyy-mm-dd")
```

也支持 `yyyy/mm/dd`、`yyyymmdd`。月、日不要前导 0（`2026/9/16`、`2026/9/1`）用：

```
=TEXT({凭证日期},"yyyy/m/d")
=TEXT({交货日期},"yyyy/m/d")
```

`mm`/`dd` 补成两位数，`m`/`d` 不补零。BOM 备注和列格式使用同一套公式引擎，覆盖 Excel 常见函数，例如：

- 逻辑：`IF` / `IFS` / `IFERROR` / `AND` / `OR` / `NOT` / `XOR` / `SWITCH`
- 数学：`SUM` / `ROUND` / `ROUNDUP` / `CEILING` / `FLOOR` / `MOD` / `POWER` / `SQRT` / `ABS` / `INT` / `PI`
- 统计：`AVERAGE` / `MIN` / `MAX` / `MEDIAN` / `COUNT` / `COUNTIF` / `SUMIF` / `LARGE` / `SMALL`
- 文本：`LEFT` / `RIGHT` / `MID` / `LEN` / `TRIM` / `SUBSTITUTE` / `FIND` / `SEARCH` / `TEXT` / `VALUE` / `CONCAT` / `TEXTJOIN`
- 日期：`TODAY` / `DATE` / `YEAR` / `MONTH` / `DAY` / `EOMONTH` / `EDATE` / `DAYS` / `NETWORKDAYS` / `WORKDAY`
- 其他：`CHOOSE` / `MATCH` / `VLOOKUP` / `CONVERT`（如 mm↔m）/ `HEX2DEC` / `PMT` / `FV`

也支持 `2^3`、`10%`、`TRUE`/`FALSE`，以及中文名 `如果`、`与`、`或`、`求和`、`四舍五入`。不含需单元格区域或动态数组的函数（如 `FILTER`、`LAMBDA`、透视/立方体）。
