# BOM 扫码质量监管系统（通用版）

基于 BOM + 总包订单 + 配件订单生成总包/子件标签，出货扫码做齐套校验的局域网系统。

## Windows 两步上手

详细说明见项目内 **`使用说明.txt`**。

| 步骤 | 双击文件 | 说明 |
|------|----------|------|
| ① 配置（首次） | **`1-配置环境.bat`** | 安装依赖（等同命令行安装） |
| ② 启动（日常） | **`2-启动系统.bat`** | 启动服务并打开浏览器 |

启动后访问：http://127.0.0.1:3789  

默认账号：`admin` / `admin123`（导入：`import` / `import123`；扫码：`scan` / `scan123`）

### 命令行等价操作

在**项目文件夹**地址栏输入 `cmd` 后执行：

```bat
"%ProgramFiles%\nodejs\node.exe" scripts\windows-setup.js
"%ProgramFiles%\nodejs\node.exe" server\index.js
```

需要 Node.js **22.5+**（官网 Windows x64，勾选 Add to PATH）。本版使用 Node 内置 SQLite，无需 Visual Studio。

> 关闭「2-启动系统」窗口 = 停止服务。

## 功能概览

- 上传 BOM 后自选母件列与母件值（同母件可多版本共存）
- 导入总包订单、配件订单（Excel），可保存列映射规则
- 订单先按自定义列关联总包与配件，再按料号匹配 BOM（不校验用量）
- 齐套数量在扫码时按已关联配件订单行判定
- 匹配成功可生成标签；标签模板支持表格、公式、唯一码；总包/配件可分开打印，适配 A4/标签纸；无订单也可自定义内容打印；支持一般订单 Excel 绑定列打印
- 扫码入库 + 扫码查单 + **计数扫码**；齐套后扫下一总包不误报缺漏
- **计数订单**：导入订单后可配置整除/余数等衍生列，指定识别列与目标数量列，扫码累计到达即提示满足并进入下一行
- 角色：导入打印 / 扫码入库 / 管理员；记录查询与 Excel 导出

## Linux / macOS

```bash
cd bom-scan-qc
npm install
npm start
```

需要 Node.js **22.5+**。改端口：`PORT=8080 npm start`

## 从旧版本升级

1. 更新到本仓库最新代码  
2. 删除项目里的 `node_modules`  
3. 再双击 **`1-配置环境.bat`**  

旧数据库文件 `data/qc.db` 可继续使用。

## 常见问题

| 现象 | 处理 |
|------|------|
| 双击提示找不到 Node | 安装 Node 22.5+；脚本会优先使用 `C:\Program Files\nodejs\node.exe` |
| 在用户目录执行 npm 报没有 package.json | 必须进入**项目文件夹**再操作 |
| 配置失败 | 查看 `setup-log.txt`；换热点 / 勿放 OneDrive、U 盘 |
| 端口被占用 | 关掉已打开的「2-启动系统」窗口 |

更多见 **`使用说明.txt`**。
