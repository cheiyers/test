# BOM 扫码质量监管系统

基于 BOM + 总包订单 + 配件订单生成总包/子件标签，出货扫码做齐套校验的局域网系统。

## 功能概览

- 上传 BOM（每份一个母件，同母件多版本共存）
- 导入总包订单、配件订单（Excel），可保存列映射规则
- 按母件料号选择 BOM 版本后关联；自定义匹配字段须完全一致，数量必须相等
- 匹配成功可生成标签，失败标红待处理
- 可视化拖拽标签模板（总包绑总包订单字段，子件绑配件订单字段）
- 码内容支持「唯一编号」或「字段拼接」；支持二维码/一维码
- 扫码：先总包后子件，无顺序，不可重复；切换总包时未齐套自动「有缺漏」
- 角色：导入打印 / 扫码入库 / 管理员
- 记录查询与 Excel 导出

## 环境要求

- Node.js 18+
- 一台长期开机的电脑作为服务器，同一局域网内其他电脑用浏览器访问

## 安装与启动

```bash
cd bom-scan-qc   # 或本仓库根目录
npm install
npm start
```

默认端口：`3789`

- 本机：http://127.0.0.1:3789
- 局域网：http://服务器IP:3789

可用环境变量改端口：

```bash
PORT=8080 npm start
```

## 示例文件

仓库 `samples/` 目录提供可直接试用的 Excel：

- `bom.xlsx` — 母件 M-100，含子件料号+规格（含同料号不同规格）
- `master_order.xlsx` — 两行总包订单
- `accessory_order.xlsx` — 对应配件；第二单故意数量不符，用于验证「部分生成」

## 推荐使用流程

1. **导入打印员** 上传 BOM，映射母件料号/子件料号/数量/匹配字段  
2. 导入总包订单 + 配件订单，映射订单号、母件料号、子件料号等  
3. 按母件选择 BOM 版本，勾选匹配字段，执行关联  
4. 在「标签模板」中调整总包/子件模板  
5. 「生成打印」仅对匹配成功行出标签，用浏览器打印（普通机或标签机）  
6. **扫码员** 在「扫码入库」先扫总包再扫子件  
7. 在「记录报表」按订单号/日期查询并导出 Excel
