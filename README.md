# 订单转换系统

单文件离线 Web 应用：上传订单与 BOM Excel（或手输母件料号），完成匹配、公式计算、参数映射，并导出带成本的生产明细。

## 使用方法

1. 用浏览器直接打开 `订单转换系统.html`（支持 `file://`，无需服务器）
2. **订单上传模式**：下载模板 → 上传订单/BOM → 匹配 → 公式/参数 → 预览计价 → 导出
3. **手输料号模式**：不上传订单，输入母件代码匹配 BOM 库，手填参数后生成清单
4. BOM 可「保存到列表」，点击列表项即可在界面中显示并直接修改母件/子件；公式配置默认折叠，点击行或「全部展开」查看编辑
5. 清单可填单价，自动计算金额与总成本并导出

## 功能概要

- 内嵌 SheetJS，完全离线可用
- 多 BOM 库、级次 1/2、备注公式与参数别名
- 保存的 BOM 可加载到编辑区，应用修改后写回列表
- 公式配置折叠展示，避免长公式占满屏幕
- 合并相同订单行；导出与预览一致（同单号表头只显示一次）
- 清单可填单价，自动计算金额与总成本并导出
