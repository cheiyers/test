# 算料

在浏览器里打开 `index.html`。数据保存在本机浏览器中，可以用侧栏的「导出备份 / 导入备份」带走。

1. 在「BOM 库」上传 Excel。每个工作表里，从「级次 = 母件」到下一个母件之前是一份 BOM；没有母件的工作表会忽略。
2. 在「物料单价」为每个物料代码填写一个单价。
3. 在「订单」上传订单。第一行是表头，每一行是一条需求。
4. 在「匹配方案」指定母件料号列、订单号列，以及每个参数对应的订单列或公式。公式用 `[列名]` 引用同一行的其他列。
5. 在「计算导出」计算结果。数量 = BOM 数量 × 备注结果；数量留空时按 1 计算，损耗率不参与。可以按订单合并相同物料，或把全部订单合并。导出前可以上传模板，用第一行表头对应系统字段。
