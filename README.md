# 通力采购订单批量识别

浏览器端 HTML 工具，用于批量解析 KONE Elevators 采购订单 PDF，把每一行 Pos 识别成可筛选、可导出的表格。

## 文档约定

样张都是 `KONE Elevators Co. Ltd. Purchase order`：

- **抬头**：PO 号、供应商、买方、送货地址、日期、账期、币种、总金额
- **订单行（主结果）**：Pos、物料号、到货日、数量、单价、金额、描述、Sales order ref、Project ref、发货说明
- **行内规格**：如轿内净高、Wire Length，可用自定义关键字抽成独立列
- **BOM 子件**：电气物料下的 `.1 0010 KM…` 零件层，以及子件下方 Remarks line（A/B/C/D）
- **页脚条款**：每页重复，不作为订单行

识别后按相同物料类别归组，由用户勾选要保留的类；订单行字段、规格字段、子件字段均可自定义。显示方式可选：仅订单行 / 展开子件 / 子件独立成行。

## 使用

用本地静态服务打开（直接双击 `index.html` 时，示例 JSON / 样张 PDF 可能因浏览器安全策略无法加载，上传 PDF 仍可用）：

```bash
python3 -m http.server 8080
```

浏览器打开 http://localhost:8080

- 页面先展示三份样张的预识别结果
- 按类别勾选（如 LED STRIP、主开关、井道电缆）；可全选 / 全不选
- 自定义订单行字段、规格关键字列、子件字段（含备注 A/B/C/D）
- 每一列可单独处理：查找替换、正则提取、按分隔符取段、日期/数值格式、值映射等；表格与导出使用处理后的值
- 显示方式：仅订单行、订单行下展开子件、子件展开为独立行
- 导出 Excel（订单行 + 按所选字段导出的 BOM 子表）、CSV、JSON

## 命令行提取

```bash
python3 -m pip install pymupdf
python3 tools/extract_po.py samples/*.pdf -o data/demo.json
```
