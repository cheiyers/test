# 订单转换系统

单文件离线 Web 应用：上传订单与 BOM Excel，完成四层匹配、公式计算、参数映射，并导出生产明细。

## 使用方法

1. 用浏览器直接打开 `订单转换系统.html`（支持 `file://`，无需服务器）
2. 按步骤操作：上传文件 → 匹配配置 → 公式配置 → 参数映射 → 输出映射 → 预览 → 导出
3. BOM、参数映射与方案可保存到本地（`localStorage`；不可用时自动回退内存）

## 功能概要

- 内嵌 SheetJS（`xlsx.full.min.js`），下载后完全离线可用
- BOM 自动检测表头行、级次列、备注公式列
- 匹配策略：精确 / 模糊前缀 / 规格型号 / 客户物料号
- 公式引擎：IF/AND/OR/ROUND/ROUNDUP 等，支持中文规则转换与变量赋值
- 参数映射、输出模板、方案保存/加载
- 合并相同订单行、用量为 0 不导出、调试面板与 Toast 提示
